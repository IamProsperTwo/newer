# Sample Crop Yield Dashboard

A small demo project showing how to structure and submit a solution for the NISR 2026 Big Data Hackathon.

**Note:** The dataset in `data/` is synthetic (made up) and only for demonstration.

## What it does
- Lets you pick a crop
- Shows two graphs: average yield by district and average yield by season

## Project structure
```
sample_hackathon_project/
  app.py                      # Streamlit app
  requirements.txt            # Python packages needed
  README.md                   # This file
  data/sample_crop_yield.csv  # Sample dataset
```

## How to run
```
pip install -r requirements.txt
streamlit run app.py
```
